# 付録: 入力パラメータと出力の対応

入力パラメータを変化させたときに `TrState` の出力がどう動くかをまとめます.
ここで扱うのは **(1) 代数的に決まる関係** と **(2) 物理スケーリングとして
広く知られている定性的傾向** に限ります. 輸送モデル (`MDLKAI` など) の
選び方で結果が大きく変わる量については個別シミュレーションが必要なので
触れません ({doc}`appendix-mdlkai` 参照).

```{admonition} 凡例
:class: note

- **↑**: 入力を増やすと出力も増える (単調増加)
- **↓**: 入力を増やすと出力は減る (単調減少)
- **=**: 入力に等しい / 直接決まる
- **⊕**: 入力を ON にすると追加項として現れる
- **〜**: 概ね成り立つ (高次効果で逆転しうる)
```

## 1. 代数的・直接的に決まる関係

シミュレーションを走らせなくても確実に決まるもの.

| 入力 | 出力 | 関係 | 備考 |
|---|---|---|---|
| `DT` × `NTMAX` | `T` (時刻) | `T = DT × NTMAX` | run 完了時の最終時刻 |
| `NSMAX` | `state.nsmax` | `nsmax = NSMAX` | 出力配列の第 2 軸サイズ |
| `RIPS = RIPE` | プラズマ電流 | 全時刻で `Ip = RIPS` (定常) | 異なる値だと線形傾斜 |
| `RIPS ≠ RIPE` | プラズマ電流 | 時刻 0 で `RIPS`, 終了時刻で `RIPE`, 線形補間 | — |
| `MODELG = 3` | 必須入力 | `KNAMEQ` のファイル存在が必要 | 無いと {doc}`parameter-setting` の `validate()` が `FILE_MISSING` |
| `MDLNB = 0` | NBI 系 | `PNBR0`, `PNBRW`, `PNBENG`, `PNBRTG` 全て無視 | — |
| `MDLEC = 0` | ECRF 系 | `PECCD`, `PECR0`, `PECRW`, `PECNPR` 無視 | — |
| `MDLLH = 0` | LH 系 | `PLHCD`, `PLHR0`, `PLHRW`, `PLHNPR`, `PLHTOT` 無視 | — |
| `MDLIC = 0` | ICRF 系 | `PICCD`, `PICR0`, `PICRW`, `PICNPR` 無視 | — |
| `MDLPEL = 0` | ペレット | ペレット粒子源無し | — |
| `MDLNF = 0` | 核融合 | DT/DHe³ 反応無し → α 粒子加熱無し | — |
| `MDLIMP = 0` | 不純物 | `PNC` 無視, `ZEFF0 ≈ 1` | 純粋な水素プラズマ近似 |

## 2. 物理スケーリングとして既知の傾向

研究領域で広く受け入れられている定性的傾向. 絶対値はモデル依存だが
方向 (増減) はおおむねモデル非依存.

### 2.1 幾何・装置 (`RR`, `RA`, `RKAP`, `BB`)

| 入力 | 主に影響する出力 | 方向 | 物理的根拠 |
|---|---|---|---|
| `RR` ↑ | `WPT` | ↑ | プラズマ体積 $V \propto R \cdot a^2$ |
| `RA` ↑ | `WPT` | ↑↑ | $V \propto R \cdot a^2$ — `RA` の方が効きが強い |
| `RKAP` ↑ (楕円率) | `WPT` | ↑ | 体積 $\propto \kappa$, さらに安定性向上で密度上限が上がる |
| `BB` ↑ | `BETA0`, `BETAA` | ↓ | $\beta = 2\mu_0 p / B^2$ |
| `BB` ↑ | `Q0`, `QP` | ↑ | $q \propto B / I_p$ |
| `BB` ↑ | `TAUE1`, `TAUE2` | 〜↑ | 多くのスケーリング則で $\tau_E \propto B^{0.15{\sim}0.3}$ |

### 2.2 プラズマ電流 (`RIPS`, `RIPE`)

| 入力 | 主に影響する出力 | 方向 | 物理的根拠 |
|---|---|---|---|
| `RIPS` ↑ | `AJT` (全電流) | = | 直接決まる |
| `RIPS` ↑ | `Q0`, `QP` (全 $q$) | ↓ | $q \propto B / I_p$ |
| `RIPS` ↑ | `RQ1` ($q=1$ 面の半径) | ↑ | $q$ プロファイル全体が下がるので $q=1$ 面が外側へ |
| `RIPS` ↑ | `BETAN` (規格化 $\beta$) | ↓ | $\beta_N = \beta_A / (I_p/(aB))$ — 分母増 |
| `RIPS` ↑ | `TAUE1`, `TAUE2` | 〜↑ | スケーリング則は $\tau_E \propto I_p^{0.7{\sim}0.9}$ |
| `RIPS` ↑ | `ALI` (内部インダクタンス) | 〜↓ | 電流分布が flatten する傾向 |

### 2.3 密度・温度の初期プロファイル (`PN[i]`, `PT[i]`)

| 入力 | 主に影響する出力 | 方向 | 物理的根拠 |
|---|---|---|---|
| `PN[i]` ↑ (軸密度) | `WPT` | ↑ | $W \propto \int n T\, dV$ |
| `PN[i]` ↑ | `BETA0`, `BETAA` | ↑ | $\beta \propto p = nT$ |
| `PN[i]` ↑ | `TAUE1` | 〜↑ | スケーリング則は $\tau_E \propto n^{0.4{\sim}0.5}$ |
| `PT[i]` ↑ (軸温度) | `WPT` | ↑ | 同上 |
| `PT[i]` ↑ | `BETA*` | ↑ | $\beta \propto p$ |
| `PT[i]` ↑ | `TAUE1`, `TAUE2` | 〜↓ | 温度上昇は輸送が増える傾向 |
| `PNS[i]` ↑ (縁密度) | 密度プロファイル | flatten | 中心-縁差が縮む → 勾配が下がる |
| `PTS[i]` ↑ (縁温度) | `WPT` | ↑ | 縁温度の底上げ |
| `PROFN1` ↑ | 密度プロファイル | 中央 flat | $(1-\rho^{P_1})^{P_2}$ の指数が立つ |
| `PROFN2` ↑ | 密度プロファイル | 外側急峻 | 同上 |

### 2.4 加熱系 (`MDLNB`, `MDLEC`, `MDLLH`, `MDLIC`)

| 入力 | 主に影響する出力 | 方向 | 物理的根拠 |
|---|---|---|---|
| `MDLNB ≥ 1` (NBI ON) | `WPT` | ⊕↑ | 外部加熱パワーが加わる |
| `MDLNB ≥ 1` | `AJT` | ⊕↑ | NB 駆動電流分が加わる |
| `MDLNB ≥ 1` | `TAUE1` | 〜↓ | Power degradation: $\tau_E \propto P^{-0.5{\sim}-0.7}$ |
| `PNBENG` ↑ | NB ドライブ電流 | ↑ | 高エネルギービームほど CD 効率が上がる |
| `MDLEC ≥ 1` (ECRF ON) | `WPT`, $T_e$ プロファイル | ⊕↑ | 局所電子加熱 |
| `MDLLH ≥ 1` (LH ON) | `AJT` | ⊕↑ | LH 電流駆動 |
| `MDLLH ≥ 1`, `PLHTOT` ↑ | `WPT` | ⊕↑ | 入力パワー比例 |
| `MDLIC ≥ 1` (ICRF ON) | $T_i$ プロファイル | ⊕↑ | 局所イオン加熱 |
| `PNBR0`, `PECR0` を中心側へ | プロファイルピーキング | ↑ | 加熱位置で温度勾配が立つ |

### 2.5 輸送係数の単純スケール (`CK0`, `CK1`)

`MDLKAI` が定数係数モデル (`0`–`9`) のときに直接効きます.

| 入力 | 主に影響する出力 | 方向 | 物理的根拠 |
|---|---|---|---|
| `CK0` ↑ (電子 χ 係数) | $T_e$ プロファイル | flatten | 拡散率増加 |
| `CK0` ↑ | `WPT` | ↓ | $T_e$ 低下 |
| `CK0` ↑ | `TAUE1`, `TAUE2` | ↓ | $\tau_E \propto 1/\chi$ |
| `CK1` ↑ (イオン χ 係数) | $T_i$ プロファイル | flatten | 同上 |
| `CK1` ↑ | `BETAN` | ↓ | $T_i$ 低下 |

### 2.6 不純物 (`MDLIMP`, `PNC`)

| 入力 | 主に影響する出力 | 方向 | 物理的根拠 |
|---|---|---|---|
| `MDLIMP ≥ 1`, `PNC` ↑ | `ZEFF0` | ↑ | $Z_\text{eff} = \sum Z_i^2 n_i / n_e$ |
| `MDLIMP ≥ 1`, `PNC` ↑ | 放射損失 (`PRADT` 等) | ↑ | 高 Z 不純物の制動・線放射 |
| `MDLIMP ≥ 1`, `PNC` ↑ | `WPT` | ↓ | 放射損失↑によるエネルギー損失 |

### 2.7 核融合 (`MDLNF`)

| 入力 | 主に影響する出力 | 方向 | 物理的根拠 |
|---|---|---|---|
| `MDLNF ≥ 1` (DT ON) | `WPT` | ⊕↑ | α 粒子加熱 (3.5 MeV/反応) |
| `MDLNF ∈ {2, 4, 6}` | `PN[2]`, `PN[3]` (D, T) | ↓ | DT 燃焼で D, T が消費 |
| `MDLNF ∈ {2, 4, 6}` | `PN[4]` (He) | ↑ | α 粒子の蓄積 |

## 使い方

特定の出力を狙った値に持っていきたいときに, この表で「どの入力を動かすか」
の見当をつけます. 例:

- **`BETAN` を上げたい** → `PN`/`PT` を上げる, または `BB` を下げる, `Ip` を下げる
  (ただし `BB` を下げすぎると安定性悪化, `Ip` 下げすぎると `q` 上昇で別問題)
- **`TAUE1` を伸ばしたい** → `Ip`, `B`, `n` を上げる; 逆に加熱 `P` は控えめに
  (power degradation)
- **`AJT` の内訳を見たい** → `MDLNB`, `MDLLH`, `MDLEC` を切り替えながら
  `MDLJBS` も振る

定量的な感度 (例: `RR` を 10% 上げると `WPT` は何 % 上がるか) は
シミュレーションを走らせて確認してください — `tr_sweep` の枠組みが
そのために用意されています ({doc}`testing` Layer 4).
