# check_dealloc.py 使い方マニュアル

## これは何をするスクリプトですか？

Fortran プログラムでは、`ALLOCATE` でメモリを確保したら、使い終わったあとに
`DEALLOCATE` で解放する必要があります。解放し忘れると「メモリリーク」が起き、
プログラムが不安定になったり異常終了する原因になります。

このスクリプトは、`ALLOCATE` で確保した変数に対して `DEALLOCATE` が
書かれているかどうかを自動的にチェックします。

## 必要なもの

- Python 3（バージョン 3.6 以上）

## 基本的な使い方

### 1つのパッケージをチェックする

```bash
cd /home/k-yoshimi/program/task
python3 tools/check_dealloc.py tr
```

これで `tr/` ディレクトリ内の全 Fortran ファイル (.f90, .f) をチェックします。

### 全パッケージを一括チェックする

```bash
cd /home/k-yoshimi/program/task
python3 tools/check_dealloc.py .
```

task/ 配下の全パッケージをまとめてチェックします。

### .f90 ファイルだけチェックする

```bash
python3 tools/check_dealloc.py tr --f90-only
```

古い .f ファイルを除外して .f90 ファイルだけを対象にします。

## オプション一覧

| オプション | 説明 |
|-----------|------|
| (なし) | 全ての結果（OK と 漏れ）を表示 |
| `--missing-only` | 漏れ（DEALLOCATE がないもの）だけ表示 |
| `--summary` | パッケージ毎の集計だけ表示（詳細を省略） |
| `--f90-only` | .f90 ファイルのみ対象 |
| `-h`, `--help` | ヘルプを表示 |

**[OK]** の行は、ALLOCATE に対応する DEALLOCATE が見つかったことを示します。

**[漏れ]** の行が、DEALLOCATE が見つからなかった変数です。

```bash
python3 tools/check_dealloc.py . --f90-only --summary
```


## よく使うコマンドの組み合わせ

### 漏れだけを見たい場合（最もよく使う）

```bash
python3 tools/check_dealloc.py tr --f90-only --missing-only
```

### 全パッケージの状況を一覧で把握したい場合

```bash
python3 tools/check_dealloc.py . --f90-only --summary
```

### 特定パッケージの漏れだけ見たい場合

```bash
python3 tools/check_dealloc.py wmx --f90-only --missing-only
```

## 注意事項

- このスクリプトは**静的チェック**です。ソースコードのテキストを検索するだけで、
  実際にプログラムを実行するわけではありません。
- サブルーチン内のローカル変数は、サブルーチンを抜けると自動的に解放される
  場合があります。[漏れ] と表示されても、必ずしも全てが修正必要とは限りません。
- モジュール変数（MODULE 内で宣言された ALLOCATABLE 変数）の DEALLOCATE 漏れは
  メモリリークの原因になるため、優先的に修正してください。
- 構造体メンバ（`%` を含む変数名）も検出できます。

## トラブルシューティング

### 「エラー: ... はディレクトリではありません」と出る場合

パスが間違っています。スクリプトにはディレクトリのパスを指定してください。

```bash
# 正しい例
python3 tools/check_dealloc.py tr

# 間違い（ファイルを指定している）
python3 tools/check_dealloc.py tr/trcomm.f90
```

### 結果が多すぎて見づらい場合

`--missing-only` で漏れだけに絞るか、`--summary` で概要だけ見てください。

```bash
python3 tools/check_dealloc.py . --f90-only --summary
```
