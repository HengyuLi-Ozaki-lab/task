========
概要
========

TXnewとは
=========

TASK/TXnewは、トカマクプラズマの1次元（径方向）輸送シミュレーションコードです。
磁気流体平衡を仮定し、プラズマの密度・温度・速度場の時間発展を計算します。

特徴
====

物理モデル
----------

* **多流体モデル**: 電子・イオン・不純物を独立に扱う
* **ネオクラシカル輸送**: NCLASSコードによる新古典輸送係数の計算
* **異常輸送**: 複数の乱流輸送モデルをサポート
* **加熱モデル**: NBI、ICRF、ECRFなどの加熱源
* **中性粒子**: リサイクリング、ガスパフ、電荷交換

変数体系
--------

TXnewでは以下の変数体系を使用します：

.. list-table:: 変数インデックス
   :header-rows: 1
   :widths: 15 15 50 20

   * - グループ
     - 変数
     - 説明
     - インデックス
   * - 磁気流体
     - LQm1-LQm5
     - 磁気流体5方程式
     - 1-5
   * - 電子
     - LQe1-LQe8
     - 電子の8変数
     - 6-13
   * - イオン
     - LQi1-LQi8
     - イオンの8変数
     - 14-21
   * - 不純物
     - LQz1-LQz8
     - 不純物の8変数
     - 22-29

主要な変数
----------

各プラズマ種（電子/イオン/不純物）について：

* **LQx1**: 密度 :math:`n`
* **LQx2-LQx4**: 運動量密度 :math:`n \mathbf{u}`
* **LQx5**: 熱エネルギー密度 :math:`n T`

座標系
======

TXnewは以下の座標系を使用します：

* **ρ座標**: 規格化小半径 :math:`\rho = r/a` （0 ≤ ρ ≤ 1）
* **NRMAX**: 径方向格子点数

境界条件
========

* **中心 (ρ=0)**: Neumann条件（対称性）
* **端 (ρ=1)**: 各変数ごとに設定可能

時間積分
========

* **陰解法**: BDF (Backward Differentiation Formula) 法
* **Newton-Raphson反復**: 非線形方程式の解法
* **時間刻み**: 適応的またはユーザー指定
