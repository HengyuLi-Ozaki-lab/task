=============
入力パラメータ
=============

TXnewの入力パラメータはNamelist形式（&tx ... &end）で指定します。

入力ファイル形式
================

.. code-block:: fortran

   &tx
     RR = 3.2
     RA = 0.8
     BB = 2.68
     PTe0 = 2.0
     PTi0 = 2.0
     NTMAX = 1000
     DT = 1.0D-3
   &end

初期プロファイルパラメータ
==========================

密度プロファイル
----------------

初期密度分布は以下の形式で与えられます：

.. math::

   n(\rho) = (n_0 - n_a)(1 - \rho^{p_1})^{p_2} + n_a

.. list-table::
   :header-rows: 1
   :widths: 15 50 15 10

   * - パラメータ
     - 説明
     - デフォルト
     - 単位
   * - PN0
     - 電子密度（軸上）
     - 0.2
     - 10²⁰ m⁻³
   * - PNa
     - 電子密度（端）
     - 0.05
     - 10²⁰ m⁻³
   * - PROFN1
     - 密度プロファイル指数 p₁
     - 2.0
     - \-
   * - PROFN2
     - 密度プロファイル指数 p₂
     - 1.0
     - \-

温度プロファイル
----------------

初期温度分布は以下の形式で与えられます：

.. math::

   T(\rho) = (T_0 - T_a)(1 - \rho^{p_1})^{p_2} + T_a

     - keV

     - keV
